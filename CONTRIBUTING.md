# Contributing

Thanks for taking an interest in TaskFlow.

## Before opening a pull request

- Keep changes focused and easy to review.
- Do not commit local credentials or `config/env.php`.
- Run `php -l` against changed PHP files.
- Test both English and Arabic layouts when changing UI code.
- Test permission changes with the affected role and with a user who should not have the permission.
- Keep the database setup script compatible with a fresh database.

For larger changes, describe the user-facing behavior and any database changes in the pull request.
